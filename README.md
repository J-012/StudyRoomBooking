# Study Room Booking Tool

A basic ASP.NET Core MVC application developed for
ITPE3200 Web Applications at OsloMet.

## Technologies

- .NET 10
- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQLite
- Razor Views
- Bootstrap

## Requirements

- .NET SDK 10
- Node.js is not required to run the current MVC application.

## How to run

1. Open a terminal in the project directory.
2. Restore dependencies:

   dotnet restore

3. Run the application:

   dotnet run

4. Open the localhost URL displayed in the terminal.

## Database

The application uses SQLite through Entity Framework Core.
The database is created automatically if it does not already exist.
